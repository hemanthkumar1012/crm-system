# Support CRM System

A full-stack customer support ticketing system built with Node.js, Express, SQLite, and React (Vite + Tailwind CSS).

## Features
- Create new support tickets with auto-generated IDs
- Dashboard with real-time stats
- Search and filter by status
- View detailed ticket history and add notes
- Update ticket status
- Priority levels

## Setup Instructions

### Backend
1. Navigate to the `backend` directory: `cd backend`
2. Install dependencies: `npm install`
3. Start the server: `node server.js` (runs on http://localhost:3000)

### Frontend
1. Navigate to the `frontend` directory: `cd frontend`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev` (runs on http://localhost:5173)
